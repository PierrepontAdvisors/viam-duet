07 · It's just points

Tracy and my robot follow the same thing: a list of points.

Tracy (your turtle)
from turtle import *
points = [(40, 0), (40, 40),
          (0, 40), (0, 0)]
penup()
goto(0, 0)
pendown()
for x, y in points:
    goto(x, y)
penup()
My robot (simplified)
stroke = points_from_claude()
# Claude picks the shape; we just walk it
x, y = stroke[0]
pen_up()
move_to(x, y)
pen_down()
for x, y in stroke[1:]:
    move_to(x, y)
pen_up()
