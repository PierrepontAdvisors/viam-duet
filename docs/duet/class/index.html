02 · What a hackathon is
  • Friday 9 am to Saturday 6 pm. Doors lock at night.
  • Teams of 2 or 3. A real robot arm each.
  • Demo at 3:30. Awards at 5.

A hackathon is a weekend where people show up to a room with a problem and try to build something real before the time runs out. Viam, a company that makes software for robots, lent every team a real arm. The theme was fine motor skills: plug in a charger, pour water, stack Jenga, sort recycling, move an egg. Or bring your own idea. I brought my own.

07 · It's just points

Your turtle and my robot follow the same thing: a list of points.

Your turtle
import turtle
t = turtle.Turtle()
points = [(40, 0), (40, 40),
          (0, 40), (0, 0)]
t.penup()
t.goto(0, 0)
t.pendown()
for x, y in points:
    t.goto(x, y)
t.penup()
My robot (simplified)
stroke = points_from_claude()
# e.g. [(0, 0), (40, 0), (40, 40)]
x, y = stroke[0]
pen_up()
move_to(x, y)
pen_down()
for x, y in stroke[1:]:
    move_to(x, y)
pen_up()

Left is turtle: pen up, go to the start, pen down, go through a list of points, pen up. Right is my robot, simplified: pen up, move to the start, pen down, go through a list of points, pen up. Same program. Mine has a motor.

09 · What broke

The robot crushed the pen.

I measured the board with the marker in my hand. The robot holds it 27 mm differently.

Measure with the robot's hand, not yours.

The first line it ever drew, it pushed so hard it flattened the marker tip. I had touched the marker to the corners of the board with the marker in my hand; the robot holds it 27 millimetres differently, more than an inch. Teaching it the corners again with the marker in its own grip fixed it. The mistake said exactly what was wrong.

10 · What broke

The smart trigger that wasn't.

I wrote clever code so the robot would notice when you'd stepped back.

It fired every few seconds on an empty board.

Saturday morning I deleted it and added a button.

Go, robot!

The simple thing is allowed to win.

I was proud of this one before it broke: the robot would notice by itself, through the camera, when you had finished and stepped back. No button. At the table on Saturday it fired every few seconds on an empty board. I spent an hour on it, deleted it, and added a button that says Go, robot. The button worked all day and nobody missed the magic.

11 · What broke
class Palletizer:
    def obstacles(self):
        boxes = self.placed_boxes()
    return WorldState(boxes)

SyntaxError: 'return' outside function

The error you'll get too.

Four spaces instead of eight. The day before the hackathon.

The error message is the clue, not the insult.

The day before the hackathon, in the practice course: SyntaxError, return outside function. The return was right there under the function. Except it was four spaces in instead of eight, so Python thought the function had ended. Indentation is the structure. The message was telling me exactly that. Read it.

12 · The log

I wrote down every problem.

  1. 1Symptom
  2. 2What I tried
  3. 3Fix
  4. 4Why it worked

Eight entries by Friday night.

This is what debugging actually is.

Every problem went in a log: what I saw, what I tried, what fixed it, why it worked. Eight entries by Friday night. More than once, writing down exactly what I saw was most of the fix, because it makes you look. Debugging is not being smart; it is being organized about being wrong. You could start one tomorrow.

14 · One piece of advice

You already know enough to start. You know turtle; that is a robot with the motor taken out. Start with the smallest thing that works, then make it bigger. Mine was a square. Then a square the robot drew. Then a shape Claude chose. Then a whole drawing. Nobody starts with the whole drawing. Questions.
