# fake

Reference for the fake encoder model. Fake encoder.
> Source: https://docs.viam.com/reference/components/encoder/fake/


The `fake` encoder is an encoder model for testing code without any hardware.




### JSON Template

```json
{
  "name": "<your-encoder-name>",
  "model": "fake",
  "api": "rdk:component:encoder",
  "attributes": {}
}
```

### JSON Example

```json
{
  "name": "myEncoder",
  "model": "fake",
  "api": "rdk:component:encoder",
  "attributes": {}
}
```



No attributes are available for `fake` encoders.
