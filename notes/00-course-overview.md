# Course overview

Source: https://viam-101-w28-9jnk.learn.viam.com/workshop/content/print.html

## What the course is (from the login page)
- Hands-on, free, no hardware or prior robotics experience required.
- Builds a real robotics application in simulation: a palletizer.
- The sample code shown uses the Python SDK with `asyncio`: a vision service returns object point clouds from a camera (`cam-1`), the code picks the largest object, builds a `PoseInFrame`, opens a gripper (`gripper-1`), and calls the motion service to move to the object. Poses are expressed in the `world` frame.
- Expect the course to cover: machine config, camera + vision service, arm + gripper components, the frame system, and the motion service.
